# teclas-facil-privacidad
DIRECTIVA DE PRIVACIDAD — TECLAS FACIL

Última actualización: 26 de octubre de 2026

1. Introducción

TECLAS FACIL es una aplicación para Windows diseñada para facilitar el acceso a determinadas teclas y combinaciones de teclado mediante una interfaz sencilla y accesible.

La privacidad de los usuarios es importante. Esta directiva explica cómo la aplicación gestiona la información durante su uso.

2. Recopilación de datos personales

TECLAS FACIL no recopila, solicita ni transmite deliberadamente datos personales de los usuarios.

La aplicación no requiere crear una cuenta ni iniciar sesión para utilizar sus funciones principales.

3. Almacenamiento local

La aplicación puede guardar preferencias y configuraciones necesarias para su funcionamiento en el equipo del usuario, mediante archivos locales de configuración.

Estos datos se utilizan exclusivamente para conservar las preferencias de la aplicación. No se envían a servidores externos ni se comparten con terceros por parte de TECLAS FACIL.

4. Uso del teclado y de las combinaciones de teclas

TECLAS FACIL permite ejecutar acciones de teclado seleccionadas por el usuario, incluidas determinadas combinaciones de teclas.

La aplicación no está diseñada para registrar de forma general las pulsaciones del teclado, recopilar contraseñas ni supervisar la actividad del usuario fuera de las acciones solicitadas mediante su interfaz.

5. Compartición de información

TECLAS FACIL no vende, alquila ni comparte información personal de los usuarios con terceros.

La aplicación no incorpora publicidad ni herramientas de seguimiento publicitario, siempre que estas funciones no se añadan en futuras versiones.

6. Conexión a Internet

Las funciones principales de TECLAS FACIL están diseñadas para ejecutarse localmente en el equipo. La aplicación no necesita transmitir datos personales a Internet para realizar sus funciones básicas.

7. Seguridad

La configuración local permanece en el dispositivo del usuario. Se recomienda mantener Windows actualizado y descargar la aplicación únicamente desde fuentes oficiales o de confianza.

8. Privacidad de menores

TECLAS FACIL es una herramienta de utilidad para Windows y no está diseñada para recopilar información personal de menores ni de otros usuarios.

9. Cambios en esta directiva

Esta directiva podrá actualizarse si se incorporan nuevas funciones o si cambian las prácticas de tratamiento de datos de la aplicación. La versión actualizada indicará su fecha de revisión.
